# Congreso Tech - Taller 3 (Backend)

Backend del Congreso Universitario de Tecnología con Node.js, Express y MongoDB.

## Requisitos

- Node.js
- MongoDB en `mongodb://localhost:27017/merndb`

## Cómo ejecutar el backend

```bash
cd backend
npm install
npm run dev
```

Servidor en: `http://localhost:4000`

## API - CRUD inscripciones

| Método | Ruta |
|--------|------|
| POST | `/api/registro` |
| GET | `/api/registro` |
| GET | `/api/registro/:id` |
| PUT | `/api/registro/:id` |
| DELETE | `/api/registro/:id` |
